# AI Pest Detection System

This project identifies agricultural insects using AI (YOLO11 Classification).

## Features

- Detects Aphids
- Detects Whiteflies
- Detects Grasshopper
- Detects Ladybug

Displays:
- Confidence
- Scientific Name
- Harmful/Beneficial Status
- Affected Crops
- Recommendation

Developed using:
- Python
- Ultralytics YOLO11
- Streamlit
